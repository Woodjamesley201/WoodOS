# Changelog

## 1.0.0 — first release

- WoodOS home: frosted-glass UI, clock (3 styles) and weather widgets, app grid with folders and edit mode, dock, search, app drawer (All/Recent/Favorites).
- Control Center: quick tiles, brightness (with permission flow) and volume sliders, battery.
- Notification Shade with grouping, expansion, history, and a clear-all (notification-listener permission).
- WoodDesk: centered taskbar, Start menu, desktop icons with context menus, calendar flyout, system tray, power menu.
- Real window management for built-in desk apps: drag, resize, snap left/right, minimize, maximize, Alt+Tab, Alt+F4, Ctrl+Space, Escape.
- Desk apps: File Explorer, Notes, Calculator, Clock, Weather, Task Manager, About.
- Screen recording via MediaProjection.
- Customization: 8 wallpapers + custom image, themes, accents, clock styles, grid columns, blur/transparency/animation sliders.
- Adaptive performance layer that scales blur and motion to available memory.
- Keyboard/mouse support: right-click context menus throughout WoodDesk.
